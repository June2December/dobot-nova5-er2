# 1차 실험 기록: orient_mode 비교

위치·거리는 다섯 모드가 같다 (YOLO 박스 + depth median).

MoveIt 초록 원통도 같다. **항상 `base_link` 위로 서서 윗면이 지면과 평행**하다. 모드를 바꿔도 원통은 안 눕는다.

다른 것은 TF `cup` / RGB 축 / 로그 `object_rpy`의 **파란 Z** 뿐이다.

```bash
ros2 launch dobot_perception moveit_cup_pose.launch.py orient_mode:=<아래값>
```

RViz Fixed Frame은 `base_link`. 볼 것은 원통이 아니라 **컵에 붙은 RGB 축**.

---

## 한 줄

| `orient_mode` | 파란 Z = | 노란 시선이랑 | 컵이 서 있는 축이냐 | 흔들림 |
|---|---|---|---|---|
| `pca_max` (기본, `pca`) | 점구름에서 **제일 긴** 방향 | 보통 아님 | 옆에서 볼 때만 대충. 위에선 지름이라 눕는 축 | 있음 |
| `pca_min` | 점구름에서 **제일 짧은** 방향 | 전면만 보이면 **시선에 가까움** | 위에서 볼 때 대충 | 있음 |
| `view` (`view_ray`) | 카메라 → 컵 | **이게 시선** | 아님 | 거의 없음 |
| `plane` (`plane_ransac`) | ROI 제일 큰 평면의 수직 | 앞면이면 **시선에 가까움** | 테이블/윗면이면 예 | **큼** |
| `identity` (`none`) | 카메라 축 그대로 \(I\) | 파랑 = 카메라 +Z (내려다보면 아래) | 아님 | 없음 |

`pca_*` / `plane`은 부호를 카메라 쪽으로 잠근다 (`toward_camera`). `view`는 시선 그대로(장면 속). `identity`는 잠금 없음.

---

## 뭘 고르나

| 보고 싶은 것 | 켤 모드 | MoveIt에서 볼 것 |
|---|---|---|
| 시선이랑 파랑 겹침 | `view` | 컵 파랑 ≈ 카메라 파랑 |
| 축 고정, 위치만 | `identity` | 컵 축 = 카메라 축, 원통은 서 있음 |
| 긴 축 (옆에서 본 높이) | `pca_max` | 파랑이 이미지에서 컵이 길쭉한 쪽 |
| 짧은 축 / 전면 법선 | `pca_min` | 내려다보면 파랑이 카메라 쪽에 가까움 |
| 평면 법선 | `plane` | 위와 비슷, 더 흔들림 |

원통이 눕거나 뚜껑이 카메라를 향하는 걸로 모드를 구분하지 않는다.
