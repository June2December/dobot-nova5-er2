# plane — RANSAC 평면 법선

## 실행

```bash
ros2 launch dobot_perception cup_pose.launch.py orient_mode:=plane
```

별칭: `plane_ransac`.

## 원리

ROI 점들이 **한 평면 근처**에 많다고 가정한다. 테이블 조각이거나, 위에서 본 컵 윗면이다. 그 평면의 법선이 Z.

세 점 \(p_0,p_1,p_2\)로 법선:

\[
n = \frac{(p_1-p_0)\times(p_2-p_0)}{\|(p_1-p_0)\times(p_2-p_0)\|}
\]

평면: \(n\cdot(x-p_0)=0\).  
점 \(x\)의 거리 \(|n\cdot(x-p_0)|\). 임계값 \(\tau=8\,\mathrm{mm}\) 안을 인라이어로 센다.

80번 무작위 세 점을 뽑아 **인라이어가 가장 많은 \(n\)** 을 쓴다. 실패하면 PCA 단축으로 후퇴.

부호: 카메라 쪽을 보게 잠근다 (`toward_camera=True`).

## 수식 (RANSAC)

반복 \(k=1..80\):

1. \(\{i,j,k\}\sim\mathrm{Uniform}\)
2. \(n^{(k)}\) 계산, 퇴화(길이≈0)면 스킵
3. \(\#\{i : |n\cdot(X_i-p_0)|<\tau\}\) 최대인 \(n\) 유지

최소 인라이어 30. 아니면 `vt[-1]`.

## 볼 것

박스에 테이블이 많이 들어오면 파란 축이 테이블에 수직이어야 한다.  
컵만 가득이고 옆면이면 평면이 컵 옆구리라서 축이 옆으로 눕는다.

공장 “위아래 집기”에 가장 가까운 **이 레포 구현**이다. 테이블 법선 ≈ 접근 Z.
